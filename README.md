# Rock-Paper-Scissors
A game of rock paper scissors
Only playable on Desktop/Laptop or Tablet.

## Description
Made with HTML, CSS and javascript, and the site is made public on github pages.
if you don't know how to play rock, paper, scissors - the rules are simple. 
- Paper Beats Rock
- Rock Beats Scissors
- Scissors Beats Paper

To play press one of the options given on the buttons : 🪨 , 📄, ✂️
The website will then choose its option
And will tell you who won and who lost (or if its a tie)
The game will play again and again every time you press one of the options.
Or alternatively there is a AGAIN button (which reloads the page so you could also press ctrl + r) if you want to clear the page.
